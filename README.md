# SpeedFine Pilot PWA

Kostenloser MVP ohne Backend/API.

## Nutzung auf dem iPhone

1. Die Dateien auf einen HTTPS-Webspace laden, z. B. GitHub Pages, Netlify oder iCloud/anderer Webserver mit HTTPS.
2. URL in Safari auf dem iPhone öffnen.
3. Teilen-Button → „Zum Home-Bildschirm“.
4. App vom Home-Bildschirm starten und Standort erlauben.

Wichtig: GPS im Browser funktioniert auf iOS nur über HTTPS oder lokal. Beim Öffnen direkt aus einer ZIP-Datei funktioniert GPS meistens nicht.

## Funktionen

- Live-Geschwindigkeit per iPhone GPS
- manuelles Tempolimit
- Innerorts/Außerorts
- Bußgeld, Punkte, Fahrverbot lokal berechnet
- Offline-Cache nach erstem Laden
